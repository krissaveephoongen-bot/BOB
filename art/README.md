# bob-art: ชุด asset placeholder ของ Battle of the Brooms

ทุกไฟล์ในโฟลเดอร์นี้สร้างจากโค้ด (ไม่มีภาพหรือเสียงจากแหล่งอื่น จึงไม่มีปัญหาลิขสิทธิ์) ใช้เป็นของชั่วคราวให้ทีมทำเกมเพลย์และทดสอบใน Unity ได้ก่อน แล้วค่อยเปลี่ยนเป็นงานจริงทีหลังโดยใช้ชื่อไฟล์และขนาดเฟรมเดิม

## ดูของทั้งหมด

เปิด `prototype/index.html` ในเบราว์เซอร์ (ดับเบิลคลิกได้เลย) มีฉากทดลองที่เดิน ตีศัตรู และวางชั้นบนรถเข็นได้ พร้อมแกลเลอรีภาพ อนิเมชัน และปุ่มฟังเสียงทุกตัว

## ใช้ใน Unity

1. คัดลอก `unity/Assets/` ทั้งโฟลเดอร์ไปทับ `Assets/` ของโปรเจกต์ Unity (รวมกับ `Assets/Scripts` เดิมได้ ไม่มีไฟล์ชนกัน)
2. Unity จะตั้งค่าภาพเองตาม `Assets/Art/bob-art-manifest.json`: เป็น Sprite, ตัด sheet เป็นเฟรม, จุดหมุนที่เท้า, 9-slice ของ UI, 256 pixels per unit และตั้งเสียงเป็นโมโน Vorbis (เพลงเป็น Streaming)
3. เมนู **Bob > Art > Build Animation Clips** สร้างไฟล์ `.anim` ทุกท่า และ Animator Controller ของตัวละครกับศัตรูแต่ละตัวใน `Assets/Art/Animations/` ท่าที่เล่นครั้งเดียว (hit, defeat, cheer) มี trigger ชื่อเดียวกัน เช่น `animator.SetTrigger("hit")` ท่าวนใช้ `animator.Play("walk")`
4. เมนู **Bob > Art > Build Audio Prefab** สร้าง `Assets/Art/BobAudio.prefab` วางไว้ในฉากแรก แล้วเรียก `BobSfx.Play("place_layer")`, `BobSfx.Loop("scrub_loop", true)`, `BobSfx.Music(true)`
5. ถ้าไม่ได้นำเข้าตามที่ควร (เช่น ไฟล์ภาพเข้าก่อน manifest) ใช้ **Bob > Art > Reimport Art**

สคริปต์ runtime ใน `Assets/Scripts/Art/`:
- `BobSpriteAnimator` เล่นเฟรมโดยไม่ต้องมี Animator ใช้กับ FX และ UI Image ได้ มี `destroyWhenDone` สำหรับเอฟเฟกต์ครั้งเดียว
- `BobTween` อนิเมชันแบบ tween ด้วยโค้ด: `Pop` (หยิบของ/กดปุ่ม), `Squash` (วางชั้นลงรถเข็น), `Shake` (ปฏิกิริยาเสีย), `FloatUp` (ตัวเลขคะแนนลอย), `MoveArc` (โยนชิ้นส่วนเข้ารถเข็น), `Bob` (ลอยขึ้นลงเบาๆ)
- `BobSfx` ตัวเล่นเสียง

สคริปต์เหล่านี้ยังไม่ได้คอมไพล์ใน Unity จริง (เครื่องที่สร้างไม่มี Unity) ถ้าเจอ error แจ้งข้อความมาได้

## สร้างใหม่หรือแก้ไข

```
./tools/build_all.sh
python3 tools/make_sheets.py && node tools/render_sheets.js   # character sheets ใน docs/sheets
```
ต้องมี Python 3 + numpy และ Node + Playwright (`npm i playwright && npx playwright install chromium`) ภาพต้นฉบับเป็น SVG ใน `source/svg/` สีและรูปทรงแก้ได้ใน `tools/make_art.py` เสียงแก้ใน `tools/make_sfx.py`

## ส่วนไหนเป็น placeholder ที่ควรเปลี่ยน

- **เพลง**: แค่ลูปทดสอบจังหวะจากคลื่นสี่เหลี่ยม ควรจ้างนักแต่งเพลงหรือซื้อเพลงที่มีใบอนุญาตเชิงพาณิชย์ ไม่ควรออกเกมด้วยเพลงนี้
- **ตัวละครและศัตรู**: ตัวละคร 4 ตัวปรับทรงหัว สี และอุปกรณ์ตาม concept แล้ว (กวาด ผ้าคาดหัวแดง, ฟอง มวยคู่+ฟองน้ำ, ถู ถังบนหัว+ไม้ถู, สเปรย์ ผมบ็อบ+แว่นกันลม+ขวดชมพู) แต่ยังเป็นงาน 2D แบบง่าย ต้องให้ศิลปินทำงานจริงตาม `docs/`; ศัตรูยังเป็นชุดเดิม
- **อนิเมชัน**: ตอนนี้ 4 ถึง 8 เฟรม ขยับแค่ตัวขึ้นลงและขาสลับ งานจริงควรใช้ Spine หรือ Unity 2D Animation (bone) หรือวาดเฟรมใหม่ อาจต้องมีท่าเดินหันหลังและหันหน้าแยกกัน
- **โลโก้**: ตัวอักษรภาษาอังกฤษใช้ฟอนต์ระบบ ควรออกแบบโลโก้ไทย/อังกฤษจริง
- **เสียงเอฟเฟกต์**: ใช้ได้ระดับเกมต้นแบบ แต่เสียงน้ำ ไอน้ำ แปรงขัด ยังฟังเป็นเสียงสังเคราะห์ ควรเปลี่ยนเป็นเสียงอัดจริงหรือไลบรารีเสียงที่มีใบอนุญาต
- ที่ใช้ต่อได้นานกว่า: ไอคอน UI, ไอคอนชิ้นส่วน, ปุ่ม 9-slice, เอฟเฟกต์ประกาย/ฟอง และโครงสคริปต์ Unity (importer, animator, tween, เสียง) ซึ่งใช้กับงานจริงได้เลยถ้าคงชื่อไฟล์และขนาดเฟรมเดิม
