# 00 · Art Direction — BOB Visual Identity (2.5D Cartoon)

**แหล่งอ้างอิงหลัก (Source of truth):** `concept/BOB_Game_Art_Board.png` และ `concept/BOB_Asset_Sheet.png`
ภาพอ้างอิงอื่น (ห้อง diorama แมว, ฟองน้ำถือไม้ถู ฯลฯ) ใช้เป็น **mood ของวัสดุ แสง และมุมกล้องเท่านั้น** เป็นภาพจากเว็บไซต์ภายนอก ห้ามคัดลอกตัวละครหรือองค์ประกอบมาใช้ในเกม

## 1. หลักใหญ่ 3 ข้อ

1. **ยึดภาพต้นฉบับ ไม่ออกแบบใหม่**: ทรงผม/หมวก, สีเสื้อ, ผ้ากันเปื้อนขาว, อุปกรณ์ประจำตัว ของ 4 Heroes ต้องเหมือนใน Asset Sheet ยกระดับแค่ความละเอียด วัสดุ และมิติ
2. **อ่านออกใน 0.5 วินาทีบนจอ 6 นิ้ว**: แยกตัวละครด้วย silhouette หัว (ผ้าคาดหัว / มวยคู่ / ถังน้ำ / แว่นกันลม) + สีเสื้อ
3. **สะอาด = สว่าง ฟ้าใส มีประกาย / สกปรก = หม่น น้ำตาล ม่วงเข้ม**: ธีมทำความสะอาดเล่าด้วยสี พื้นสกปรก/พื้นสะอาด เป็น asset หลัก (ดูภาพ "พื้นสกปรก / พื้นสะอาด" ใน Asset Sheet)

## 2. Style Pillars

| องค์ประกอบ | แนวทาง | รายละเอียดเชิงผลิต |
| --- | --- | --- |
| Graphic Style | 2.5D Stylized Cartoon | โมเดล 3D + toon ramp นุ่ม 3 ขั้น + เส้นขอบน้ำตาลเข้มบาง (ไม่ใช่ดำ) ให้ดูเหมือนภาพวาดใน Art Board |
| Character | Chibi, 3D volume | สูง ~2.3 หัว, หัวโต ตาโตกลมมีไฮไลต์ 2 จุด, แก้มชมพู, มือกลม, รองเท้าบูทสั้น |
| Material | Soft matte, smooth plastic | Roughness 0.6–0.8; ข้อยกเว้น: ถังโลหะของ "ถู" และแว่นของ "สเปรย์" (metallic 0.4, roughness 0.35), สไลม์ (specular สูง กึ่งใส) |
| Lighting | Soft shadow, AO | Key light อุ่นด้านหน้าซ้ายบน `#FFF4E0`, fill ฟ้าอ่อน `#DDEBFA`, AO อบ, rim light ขาวอ่อน |
| Camera | Orthographic | มุมก้ม 40–45° (ตามภาพ In-Game Screenshot), หน้า Character Select/Upgrade ใช้ perspective FOV 25° |
| Platform | Mobile portrait & landscape | Gameplay หลัก landscape (ตาม screenshot), เมนู/อัปเกรดรองรับ portrait |
| Engine | Unity 6 LTS + URP | ดู `03_Unity_Spec.md` |

## 3. สัดส่วนตัวละคร (Chibi Standard)

| ส่วน | สัดส่วนต่อความสูง H (= 1.0 unit ไม่รวมหมวก/ผม) |
| --- | --- |
| หัว (รวมผม) | 0.44 |
| ลำตัว (เสื้อ + ผ้ากันเปื้อน) | 0.30 |
| ขา + รองเท้า | 0.26 (รองเท้ากว้าง 1.3× ขา) |
| ตา | สูง 0.10, อยู่ 55% ของหัวนับจากบน, ระยะห่าง = 1 ตา |
| อุปกรณ์ประจำตัว | ยาว ≤ 1.0 H (ไม้กวาด/ไม้ถูยาวที่สุด) |

- ทุก Hero ใช้ body เดียวกัน ต่างกันที่ หัว/ผม/หมวก (+0.05 ถึง +0.2) และอุปกรณ์ → ใช้ skeleton และอนิเมชันร่วมกันได้
- "ถู" ตัวกว้างกว่านิดหน่อยได้ (+5%) แต่ joint ต้องตรงกัน

## 5. เส้นขอบ เงา และพื้นผิว

- Outline: สีน้ำตาลเข้ม `#4A2E22` หนา 0.008–0.010 unit (บางกว่าภาพ placeholder เดิม) ปรับสีตามวัสดุได้ (เช่นขอบถังโลหะใช้เทาเข้ม)
- Toon ramp 3 ขั้น นุ่ม (soft step 0.1) เงาเป็นสีอมม่วง/ฟ้า ไม่ใช่ดำ
- Blob shadow วงรีใต้ตัว `rgba(40,30,60,0.22)`
- Texture เป็นแบบ hand-painted บางๆ (gradient + ไฮไลต์) บน albedo ไม่ใช้ normal map ละเอียด

## 6. การอ่านง่ายในเกม

- ตัวละครสูงบนจอ ≥ 120 px ที่ 1920×1080 (landscape)
- HUD ด้านบน: portrait 4 ตัว + แถบ HP เขียว (ตาม screenshot) — portrait ต้องแยกออกด้วยหัวอย่างเดียว
- ปุ่ม skill ล่างขวา วงกลมฟ้าใหญ่ + ปุ่มอุปกรณ์ 2 ปุ่มเล็ก
- พื้นสกปรกต้องต่างจากพื้นสะอาดชัดเจน (saturation −35%, decal คราบน้ำตาล/ม่วง)

## 7. Do / Don't

| Do | Don't |
| --- | --- |
| คงทรงหัว 4 แบบให้เหมือนต้นฉบับ | เปลี่ยนทรงผม/หมวก หรือสีเสื้อ |
| เส้นขอบน้ำตาลบาง เงาอมสี | เส้นดำหนา, เงาดำ |
| น้ำ/ฟองเป็นทรงกลมใสมีไฮไลต์ | ของเหลวสมจริง |
| คราบ/สไลม์ตลก ตาโต | หนอน แมลง เชื้อราแบบสมจริง |
| ใช้ภาพ ref ภายนอกเพื่อศึกษาแสง/วัสดุ | คัดลอกตัวละครหรือฉากจากภาพ ref ภายนอก |
