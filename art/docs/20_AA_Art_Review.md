# 20 · รีวิวงานอาร์ตตามมาตรฐานเกม AA

เวอร์ชัน 1.0 · 13 พ.ย. 2026 · ผู้รีวิว: Claude ในบท 3D model creator + game artist · ขอโดย Krits
ใช้คู่กับ `21_AA_Art_Bible.md` (ข้อกำหนดใหม่) และภาพอ้างอิง [`ux/BOB_AA_Art_Bible.html`](ux/BOB_AA_Art_Bible.html)

**สรุป:** concept art ของ BOB แข็งแรงพอสำหรับเกม AA แล้ว ปัญหาอยู่ที่สิ่งที่อยู่ในเกมจริงตอนนี้ ซึ่งยังห่างจาก concept มาก ในเฟรมเดียวมีสามสไตล์ปนกัน (ภาพวาดห้องกึ่งสมจริงจาก Leonardo, sprite chibi 2D, และกล่อง/โซฟาที่ Unity วาด) ไม่มี shader, แสง หรืออนิเมชันของจริง และเอกสารหลายฉบับขัดกันเรื่องฉาก ศัตรู โลโก้ และมุมกล้อง ทางแก้ที่ทำได้โดยไม่มี artist คือย้ายตัวละครและของในฉากไปเป็น 3D แบบ "สร้างจากรูปทรง" ที่ใช้ material เดียวกันทั้งเกม ผมทดลองแล้วว่าทำได้จริง: สคริปต์ `art/tools/blender/bob_kit.py` สร้างฮีโร่ 4 ตัวและศัตรู 4 ตัวพร้อม rig และอนิเมชัน ผ่านงบ polygon ทุกตัว (ข้อ 5)

## 1. "AA" สำหรับ BOB หมายถึงอะไร

ผมใช้เกณฑ์ที่วัดได้ ไม่ได้หมายถึงงบหรือขนาดทีม:

| ด้าน | เกณฑ์ AA ของ BOB |
| --- | --- |
| สไตล์ | ทุกอย่างในเฟรมมาจากภาษาภาพเดียวกัน (รูปทรง แสง เส้นขอบ พาเลต) ไม่มีชิ้นไหน "หลุดมาจากเกมอื่น" |
| อ่านง่าย | รู้ว่าใครเป็นใครจาก silhouette อย่างเดียว ที่มุมกล้องเกม บนจอ 6 นิ้ว ฮีโร่สูงบนจอ ≥ 120 px ที่ 1080p |
| การเคลื่อนไหว | ทุกการกระทำมี anticipation → action → follow-through มีน้ำหนัก หนัก-เบาต่างกัน มีหน้า 8 อารมณ์ |
| feedback | ทุกการกระทำสำคัญมีชั้น VFX + เสียง + การสั่น/หยุดเฟรมสั้นๆ ตรงจังหวะเดียวกัน |
| UI | ตัวอักษรไทยถูกต้อง คมชัด ปุ่มยืดได้ (9-slice) สถานะครบ (ปกติ/กด/ปิด) สไตล์เดียวกับโลก |
| ประสิทธิภาพ | 60 fps บนเครื่องกลาง, 30 fps บนเครื่อง 2 GB, ≤ 100k tris, ≤ 80 batches ต่อเฟรม |
| pipeline | ทุก asset ผ่านด่านตรวจเดียวกัน (ชื่อ งบ สเกล pivot silhouette) ก่อนเข้าเกม |

เกมอ้างอิงด้านระดับงาน (ใช้เทียบคุณภาพ ไม่คัดลอก): เกม co-op ปาร์ตี้แบบห้องเดียวกล้องบนลงล่าง และเกมมือถือ 3D chibi ที่อ่านตัวละครได้ชัดบนจอเล็ก

| สิ่งที่ทดลอง | ผล |

| ศัตรู 3 + บอส | เจ้าคราบ 2,452 · สไลม์ 1,826 · ขยะปีศาจ 1,084 · บอส 3,890 tris |
| rig ร่วม (ชื่อ bone ตาม 03 ข้อ 3) + อนิเมชันจากสคริปต์ | ฮีโร่: idle, walk, cheer (มี anticipation, squash, overlap); ศัตรู: idle, caught |

| ที่มุมกล้องเกม | สเปกเดิม 121 px, ข้อเสนอ AA 164 px; ทั้งฉาก ~64k tris, 53 draw calls ในเว็บ (Unity + SRP Batcher จะน้อยกว่า) |
| ทดสอบ silhouette | รอบแรกกวาดกับสเปรย์ใกล้กัน แก้ใน kit แล้ว ดู `aa/aa_silhouette_test.png` |

**ข้อจำกัดที่ต้องรู้:** โมเดลจาก kit เป็นระดับ "blockout ที่ดี" สะอาด สม่ำเสมอ rig ง่าย แต่ยังไม่มีรายละเอียดผ้า รอยพับ หรือทรงผมแบบปั้น ส่วนที่ทำให้ตัวละครมีชีวิตคือหน้า (flipbook) อนิเมชัน และ VFX ไม่ใช่จำนวน polygon ระดับนี้ใกล้เคียงเกมมือถือ 3D chibi หลายเกมที่ใช้ทรงเรียบ + สีแบน + เส้นขอบ
