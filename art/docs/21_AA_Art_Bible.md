## 1. หลัก 5 ข้อ

1. **หนึ่งโลก หนึ่ง material** ทุกอย่างในฉากเล่นเป็น 3D toon ใช้ `M_BOB_Toon` + `T_BOB_Palette` เดียวกัน ข้อยกเว้นมีแค่หน้าตัวละคร, สไลม์ (กึ่งใส), พื้นห้อง และ mask ในมินิเกม
2. **อ่านจากด้านบน** จุดจำของตัวละครต้องเห็นจากกล้องเกม 45° ไม่ใช่แค่มุมตรง ทดสอบด้วย silhouette ทุกครั้ง
3. **ความสมจริงมาจากการเคลื่อนไหว** ไม่ใช่รายละเอียดผิว: squash, overlap, หน้าเปลี่ยนอารมณ์, VFX, เสียง (ต่อยอดหลักของ 18_Tactile_Props)
4. **สะอาด = สว่างใส / สกปรก = หม่นน้ำตาลม่วง** (00 ข้อ 1) ทำด้วย shader `_DirtAmount` ใน material เดียว ไม่ใช่ภาพคนละไฟล์
5. **ทุกชิ้นผ่านด่านตรวจเดียวกัน** (ข้อ 10) ก่อนเข้าเกม ไม่ว่ามาจากสคริปต์, AI หรือ CC0

## 2. ภาษารูปทรง

| ฝ่าย | รูปทรงหลัก | กฎ |
| --- | --- | --- |
| ฮีโร่ | วงกลม + สี่เหลี่ยมมน | ไม่มีมุมแหลม; หัว 0.44 H; จุดจำอยู่บนหัวและเห็นจากด้านบน; ชุดเหมือนกัน (ผ้ากันเปื้อนครีม กางเกงกรม) |
| ศัตรู | ก้อนเหลว ฐานกว้าง ไม่มีแขนขา | แหลมได้เฉพาะคิ้วและเขี้ยว; ตาขาวโต; ห้ามซ้อนเป็นชั้นๆ แบบกองเกลียว (อ่านผิดเป็นอย่างอื่น) |
| พร็อพ | กล่อง bevel หนา | bevel ≥ 8% ของด้านสั้น; หนากว่าของจริง 1.5×; ขอบบนสว่างกว่าเล็กน้อย |
| ฉาก | ผนังเตี้ย ก้อนใหญ่ | ผนังหลังสูง ≤ 2.4 m, ผนังข้าง ≤ 1.0 m (ไม่บังตัวละคร); ของติดผนังเป็นนูนต่ำ |

**ค่าความสว่าง (value) ก่อนสี:** ฮีโร่สว่างกว่าพื้น ≥ 20%, ศัตรูเข้มกว่าพื้น ≥ 25%, ผนังและพื้นอยู่ช่วงกลาง saturation ต่ำกว่าตัวละคร ตรวจโดยแปลงภาพจอเป็นขาวดำ

- ห้าม normal map ละเอียดและห้าม PBR metallic/roughness เต็ม (ดูไม่เข้ากับ concept และหนักบนมือถือ)

## 7. Rig และอนิเมชัน

- rig ร่วม 19 bone (ชุดย่อยของ 03 ข้อ 3) skin แบบ rigid ต่อชิ้น (ไม่มีการบิดผิว ไม่ต้องลง weight เอง) ศัตรูมี 3 bone (Root, Body, Top)
- ท่าหลักสร้างจากสคริปต์ (`bob_kit.py` → `anim_hero`) ส่วนที่ต้องตอบสนองเกมทำในโค้ด (`BobSquash`, การเอียงตามความเร็ว, ผม/ผ้าคาดแกว่งแบบ spring)

| หลัก (12 principles) | ใช้ที่ไหน |
| --- | --- |
| anticipation | ย่อก่อนกระโดด (cheer), เหวี่ยงไม้กวาดถอยก่อนกวาด, ศัตรูหดก่อนโผล่ |
| squash & stretch | ลงพื้นทุกก้าว (walk), ศัตรูทั้งตัว, ของตกลงรถเข็น |
| follow-through / overlap | หัวช้ากว่าลำตัว 2 เฟรม, ผ้ากันเปื้อน, ชายผ้าคาดหัว, มวยผม |
| slow in/out | key ทุกท่าเป็น Bezier |
| arcs | แขนและไม้กวาดเคลื่อนเป็นโค้ง |
| exaggeration | ท่ายกของหนัก (T13) ตัวยุบ 15% สั่น |
| secondary action | ฟองลอยรอบฟอง, ฝุ่นจากเท้าตอนวิ่ง |

**หนัก-เบา:** ของเบา (ชิ้นส่วน ขวด) หยิบ 8 เฟรม แขนไม่ยุบ; ของกลาง (ถัง) 12 เฟรม ย่อ 5%; ของหนัก (ตู้ T13) 20 เฟรม ย่อ 15% สั่น ±1° ความเร็วเดิน −30%

**รายการท่า P0 (ฮีโร่ร่วม):** idle, walk, run, pickup, carry_idle, carry_walk, place, work (ขัด/ถู), cheer, hit (สะดุด), victory, defeat — 12 ท่า (ทำจากสคริปต์แล้ว 3)
**ศัตรู P0:** idle, spawn, caught, defeat (+ A1–A8 ใน 16 ข้อ 4.1 ทำจาก squash ในโค้ด)

## 8. VFX และ juice

**สูตร 5 ชั้นต่อ event สำคัญ** (ทุกชั้นเกิดในเฟรมเดียวกับเสียง):

| ชั้น | ตัวอย่าง (งานเสร็จ) |
| --- | --- |
| 1 รูปทรงหลัก | วงประกายขยาย 0.25 วิ |
| 2 อนุภาค | ประกาย 12 ชิ้น + ฟอง 6 |
| 3 ทิ้งร่องรอย | พื้นสะอาดแผ่ออก (decal `_DirtAmount` ลดเป็นวง) |
| 4 กล้อง/เวลา | หยุดเฟรม 40 ms (hitstop) หรือสั่น 0.1 u 0.15 วิ เฉพาะ event ใหญ่ |
| 5 UI | ตัวเลข/ไอคอนเด้งไปที่แถบทีม |

event ที่ต้องมีสูตรครบ (P0): งานเสร็จ, จับคราบฉุกเฉิน, ชิ้นส่วนลงรถเข็น, ทีมขึ้นนำ, หมดเวลา, ชนะรอบ
เทคนิค: Shuriken + flipbook ใน atlas เดียว; ทิศและสีอนุภาคมาจากพาเลต; ปิดชั้น 4 ได้ในตั้งค่า (accessibility)

### 9.2 สาย A: ขั้นตอน

1. แก้ค่าใน `bob_kit.py` (ฟังก์ชันต่อตัว เช่น `hero_sweep`) ทุกชิ้นเรียก `part(kind, สี, bone, ตำแหน่ง, หมุน, สเกล)`
2. รัน `blender -b -P art/tools/blender/bob_kit.py -- --out art/aa/kit`
3. ได้ `SK_<id>.glb/.fbx`, `T_BOB_Palette.png`, `kit_report.json` (tris เทียบงบ)
4. เปิด `ux/BOB_AA_Art_Bible.html` ดูที่มุมกล้องเกม + silhouette (ต้องเพิ่มโมเดลใหม่ใน `BOB_AA_Kit_Models.js`: รันบล็อก Python ใน `art/tools/blender/README.md`)
5. นำเข้า Unity ตาม 03 ข้อ 8 (Rig = Generic)

### 9.3 สาย B/C: ขั้นตอน

1. เลือกภาพ Leonardo ที่ตรง concept 1 ภาพ (พื้นหลังเรียบ มุม 3/4)
2. แปลงเป็น 3D (TRELLIS / Tripo / Meshy) ได้ `.glb`
3. `blender -b -P art/tools/blender/bob_prop_cleanup.py -- raw/<file>.glb --name prop_<id> --class prop_m --height <m>`
4. ตรวจ `SM_prop_<id>.json`: tris ≤ งบ, สีที่ใช้อยู่ในพาเลต
5. ผ่านด่านตรวจข้อ 10 แล้ววางใน `Assets/Art/Props/`

### 9.4 สาย 2D (ยังใช้ภาพ AI ได้)

UI, ไอคอน, หน้าเมนู, ภาพการ์ดโหมด, พื้นหลังการ์ดมินิเกม (F27) ใช้ภาพ Leonardo ได้ต่อ แต่ต้อง: ลบตัวอักษรในภาพทิ้งทุกครั้ง (ใส่ข้อความด้วย TextMeshPro), ตั้ง 9-slice, ใช้พาเลตเดียวกัน **ห้ามภาพ 2D อยู่ในฉากเล่น 3D**
