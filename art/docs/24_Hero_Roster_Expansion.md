## 1. ทำไม 8 ตัว

| เหตุผล | รายละเอียด |
| --- | --- |
| ทีม 4 คนห้ามเลือกซ้ำ (GDD 17 กฎ 4) | มี 4 ตัว = คนเลือกคนสุดท้ายไม่มีทางเลือกเลย มี 8 ตัว = คนสุดท้ายยังเหลือ 5 ตัว และทีมต้อง "เลือกว่าจะไม่เอา ability ไหน" ซึ่งเป็นเหตุผลเดิมที่ GDD เพิ่ม Wash/Press |
| หมวดถนัดเท่ากัน | มินิเกม 16 ตัว + ใหม่ 7 ตัว (ข้อ 3) แบ่งได้ราว 2-3 ตัวต่อฮีโร่ 1 ตัว ทุกคนมีงานถนัดในทุกรอบ (กติกา seed ใน 16 ข้อ 2.2) |
| ภาระถ่วงดุล | 8 ability ยังทดสอบครบได้ในห้องทดลอง (GDD 17) เกินกว่านี้ตั้งแต่เปิดเกมเสี่ยงมี ability ที่ไม่มีใครเลือก |
| ต้นทุนผลิตต่ำ | ทุกตัวใช้ `hero_body()` + rig 19 bone + 12 ท่าร่วมเดิม ต่างแค่ หัว อุปกรณ์ สี และหน้า flipbook (ข้อ 5) |

## 2. หลักออกแบบฮีโร่ใหม่ (ต้องผ่านทุกข้อ)

1. **ฐานร่วม:** สัดส่วน 1.15 u หัว 0.44 H ผ้ากันเปื้อนครีม `#FEEECF` กางเกงกรม `#2E4484` บูทน้ำตาล (01 ข้อ 0, 21 ข้อ 3) rig 19 bone และ socket เดิม
2. **จุดจำอยู่บนหัว** และไม่ซ้ำทรงกับตัวอื่นเมื่อมองจากกล้อง 45° (21 ข้อ 2) ทดสอบ silhouette ขาวดำที่ 164 px
3. **ไม่พึ่งสีอย่างเดียว:** คู่ที่สีใกล้กันสำหรับตาบอดสี (ส้ม/แดง, เขียว/มะนาว, ชมพู/ม่วง) ต่างกันที่ทรงหัวและอุปกรณ์ชัดเจน และ HUD ใช้หน้าฮีโร่เป็นไอคอน
4. **ability ไม่เพิ่มค่าพลังตรง** อยู่ในประเภทเดิม 6 ประเภทหรือประเภทใหม่ที่ไม่เพิ่มค่า มีมูลค่า ≤ งบ 15 หรือ ≤ เวลา 8 วิ (GDD 17 กฎ 2-3)
5. **หมวดถนัดต้องมีมินิเกมจริง ≥ 2 ตัว** ก่อนปล่อย ถ้ายังไม่มี ฮีโร่ตัวนั้นยังเลือกไม่ได้ (กติกา seed 16 ข้อ 2.2 บังคับให้มีงานถนัดของทุกคน)
6. **อุปกรณ์ทำความสะอาดจริงในบ้าน** ถือแบบอาวุธมหากาพย์ (GDD 14, 16) บุคลิกเป็นบวก ไม่มีตัวร้ายเป็นคน
7. **ไม่ผูกเพศหรือบทบาท** (GDD 16) ภาพอ้างอิงสลับเพศได้ ผู้เล่นเปลี่ยนผม/สีผิว/ชุดได้

## 4. ⚠ ประเด็นที่ต้องแก้: id `press` ในโค้ด

ตอนนี้โค้ด (`prototype/index.html` CHARS, `BobMatch.cs`) ใช้ id `press` สีเขียว แสดงเป็น "ถู" แต่ให้ ability **รีดเวลา** (หยุดนาฬิกา 8 วิ) ขณะที่ GDD 17 กำหนดให้ ถู = **ถังสำรอง** และรีดเวลาเป็นของตัวละคร Press (รีด) ที่แยกกัน

ข้อเสนอ (ยึด GDD): **ถูคง id `press`** (ไม่ต้องแก้ server/analytics) เปลี่ยน ability เป็นถังสำรอง และ **ฮีโร่รีดใช้ id ใหม่ `iron`** รับรีดเวลาไป แก้โค้ดในงาน task race รอบถัดไป (ยังไม่แก้ใน PR นี้)
