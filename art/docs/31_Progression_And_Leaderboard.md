## 2. ลีดเดอร์บอร์ด (ทำแล้ว 17 พ.ย. 2026)

คะแนนของแมตช์เดียว สูตรเดียวอยู่สามที่และถูกล็อกด้วยตารางเลขชุดเดียวกัน
(`BobRaceScore.Of` ฝั่งเครื่อง · `taskRaceScore` ใน `prototype/index.html` · `server/modules/index.js`):

```
raw = งานที่ทำ * 100 + เงื่อนไขรถเข็นที่ผ่าน * 75 + วินาทีที่เหลือ * 2 + (ชนะ 400 / เสมอ 150)
คะแนน = raw * (100 + 20 * (D - 1)) / 100        D1 = 1.00, D2 = 1.20, D3 = 1.40 (หารปัดลง)
```

- เพดานกันโกงเลขเฟ้อ: งานไม่เกิน 99, เงื่อนไขรถเข็นไม่เกิน 4, วินาทีที่เหลือไม่เกิน 120
- บทที่จบทั้งบทใช้ **ยอดรวมของซีรีส์** ไม่ใช่รอบสุดท้ายรอบเดียว; ช่องรถเข็นของบทนับ "ครั้งที่ล็อกผ่าน" (0–3)
  ส่วนรอบเดี่ยวนับ "เงื่อนไขที่ผ่าน" (0–4)
- การส่ง: `TaskRaceModeManager.EndMatch` ตั้ง `LastScore` → `BobRaceScoreReporter` ฟัง `MatchEnded` แล้วส่งเข้า
  `global_high_score` ครั้งเดียวต่อแมตช์ เฉพาะเมื่อ `LastMatchRecorded` และเครื่องล็อกอินแล้ว
- หน้าผล (S27) แสดง `คะแนน N · สถิติ ...` ในบล็อกรางวัล — เห็นทันทีว่าเลขที่ขึ้นบอร์ดคือเท่าไร

**ด่านที่คุมสูตรนี้:** `unity-check` (C# 10 แถว) + `server/task-race-test.js` (JS 10 แถวเดียวกัน + กฎเพดาน)
⇒ `UNITY-CHECK PASSED`, 80/80

**ข้อจำกัดที่ต้องรู้:** UGS รับคะแนนที่ client ส่ง ไม่ตรวจย้อนหลัง (ดู docs 27 §7) — กันโกงจริงต้องย้ายการคิดคะแนน
ไปเซิร์ฟเวอร์ ยังไม่ทำในเฟสนี้

## 3. ลำดับงานถัดไป (หลังลีดเดอร์บอร์ด)

1. **หน้าอันดับในเกม** — `GetTopScoresAsync` มีอยู่ แต่ยังไม่มี UI; ต้องมีป้าย "อันดับของคุณ" และปุ่มเปิดจาก Home
   (เข้าเงื่อนไข "อ่านน้อย" — ชื่อ + คะแนน + แถบสีของตัวเอง ไม่ใช่ตารางตัวเลขยาว)
2. **ดาเอนี่ (seed จากเซิร์ฟเวอร์)** — ต้องมี endpoint ออก seed ต่อวัน + ฝั่งเครื่องเก็บว่าเล่นวันนี้แล้วหรือยัง
   และหน้าจอที่บอก "วันนี้เหลือ 1 รอบ"; ห้ามใช้ `Date.now()` เป็น seed เพราะทั้งห้องต้องได้ชุดเดียวกัน
3. **ของตกแต่งที่ปลดล็อกได้** — ต้องมีตารางว่าเล่นอะไรได้อะไร (จำนวนรอบ/คะแนนสะสม) และหน้าจอเลือกสีรถเข็น/สกิน
   ใช้ `UgsCloudSaveManager.UnlockItemAndSaveAsync` ที่มีอยู่; **ไม่แตะค่าพลังหรือมินิเกม**
4. **ออนไลน์ชนะ 2 ใน 3** — ต่อจาก `BobOnlineRoom` (§10 ของ docs 27): ต้องมีผลรอบที่แชร์กัน, สถานะซีรีส์ในห้อง,
   และกติกาออกห้องกลางซีรีส์ ให้ตรงกับ `StorySeries` ฝั่งออฟไลน์
