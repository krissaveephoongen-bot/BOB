# BOB Web Spike — M1–M3

เว็บสไปค์ของ **สมรภูมิปัดกวาด (Battle of the Brooms)** ที่ย้ายเฉพาะ "กติกา + UI + มินิเกม" จาก Unity มาไว้ในเบราว์เซอร์
เป้าหมายคือตอบคำถามเดียว: *เกมนี้ยังสนุกไหมเมื่อไม่มี 3D/NavMesh/UGS* — ไม่ใช่ตัวส่งขึ้นสโตร์

## รัน

```bash
cd web-spike
python -m http.server 8123 --bind 127.0.0.1
# เปิด http://127.0.0.1:8123/
```

ต้องเปิดผ่าน HTTP เพราะใช้ ES modules (`type="module"`) — การดับเบิลคลิก `index.html` จาก Explorer จะถูก CORS บล็อก
ไม่มี build step, ไม่มี npm install, ไม่มีเซิร์ฟเวอร์เกม (onboarding เดียวกับกติกาจริง)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ฉาก 1920×1080 เดียว + หน้า splash / home / chapters / heroes / race |
| `styles.css` | design tokens (สี Mitr/IBM Plex Sans Thai) + การย่อจอด้วย `--k = min(vw/1920, vh/1080)` |
| `src/data.js` | ตัวเลข/ข้อความที่ย้ายจาก Unity: ฮีโร่ 4 ตัว, บท 6, งาน T01/T02/T05, ถังขยะ |
| `src/rules.js` | **logic ล้วน ไม่มี DOM** — เวลา คะแนน เหรียญ XP ดาว แผนรอบ schedule ของคู่แข่ง |
| `src/save.js` | `localStorage` โดยใช้ key ชื่อเดียวกับ Unity (`bob.coins`, `bob.story.stars.1`, …) |
| `src/audio.js` | WebAudio สังเคราะห์เสียง ชื่อตัวแปรตรงกับตาราง SFX ของ Unity (`broom_sweep`, `scrub_loop`, …) |
| `src/island.js` | ฉากเกาะ 2.5D บน Canvas2D (ไม่มี 3D/NavMesh — เดินเป็นจุด→จุด) |
| `src/cards.js` | การ์ดมินิเกม T01 กวาดตามทาง / T02 ถูคราบวน / T05 แยกขยะ |
| `src/app.js` | router + วนแข่ง + HUD + ผลรอบ/ผลบท + แผง self-check ตัวเลข |

## สิ่งที่พิสูจน์แล้วใน Chrome จริง (18 พ.ย.)

- เดินเส้นทางทอง: Home → เลือกบท → เลือกฮีโร่ → เกาะ → เดิน → สถานี → การ์ด → ผลรอบ → best-of-3 → ผลบท → Home
- จบ 2 รอบชนะ 2–0 → ผ่านบท: คะแนน 1230 (คำนวณตรงกับสูตร), เหรียญ +136, XP +251, เลเวล 1→2, ดาว 3, `bob.*` เขียนลง localStorage แล้วอ่านกลับหลัง reload ได้ตรง
- แพ้รอบด้วยเวลา (คู่แข่งปิดครบที่ ~112 วิ) → คราบฉุกเฉิน 2 จุดหลุด → ผลรอบ "รอบนี้ยังแพ้" ถูกต้อง
- แตะคราบฉุกเฉินแล้วเคลียร์ได้ (แก้บั๊ก: เดิมคราบเกิดทับสถานีแล้วถูก station hit-test กลืน — ตอนนี้เกิดห่างสถานี ≥130 px)
- ปุ่ม ปราม/พัก ทำงาน: คู่แข่งช้าลง 1 จังหวะ, เวลาแข่งหยุดนิ่งตอนพัก
- การ์ด T01/T02/T05 ครบ 100% ผ่าน input จริง (pointer event) — ตรวจทั้งการนับ coverage, ระยะถู (u) และการแยกถังถูก/ผิด
